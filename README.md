# Portfólio pessoal — Geovana Rogério Lima

Portfólio em HTML, CSS e JavaScript que reúne trajetória, habilidades e projetos acadêmicos e pessoais. A interface adapta-se a celular e computador, oferece temas claro e escuro com preferência salva e inclui animações sutis que respeitam a configuração de movimento reduzido do dispositivo.

## Projetos apresentados

- Sistema de Gestão de Biblioteca — análise de requisitos, protótipos de interface, diagramas de sequência e modelagem.
- [ChatBot FURIA](https://github.com/Geovanarlx/ChatBot-Furia) — chat web com respostas pré-programadas.
- [XDEVS](https://github.com/Geovanarlx/projeto-xdevs) — vitrine interativa de personagens.
- [Learning Page](https://github.com/Geovanarlx/Projeto-Learning-Page) — landing page com formulário e carrossel.
- Catálogo digital e estoque — projeto privado apresentado de forma resumida, sem link ou detalhes comerciais.
- [Relógio visual acessível](https://github.com/Geovanarlx/PrototipoRelogio) — experimento full stack com sinais visuais para sons do ambiente.
- [Coletor de anexos da ANS](https://github.com/Geovanarlx/Quest-1---python) — automação em Python para baixar PDFs e reuni-los em ZIP.

## Como visualizar

Abra `index.html` no navegador ou use a extensão Live Server no Visual Studio Code.

## Recursos

- HTML semântico, navegação por âncoras e layout responsivo.
- Alternância de tema com preferência salva localmente.
- Animações e revelação de conteúdo com suporte a `prefers-reduced-motion`.
- Monograma vetorial próprio em SVG.
- Menu mobile, ano automático e estados de foco visíveis.

## Publicação

O site é estático e pode ser publicado pelo GitHub Pages. Ative Pages nas configurações do repositório para disponibilizar o portfólio.
