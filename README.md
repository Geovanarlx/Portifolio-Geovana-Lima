# Portfólio pessoal — Geovana Rogério Lima

Site pessoal feito com HTML5 semântico, CSS3, Flexbox/Grid e JavaScript leve. O conteúdo reúne informações acadêmicas, experiências profissionais, habilidades e um projeto de análise de sistemas. A estrutura está preparada para receber novas entregas e registrar a evolução do portfólio ao longo do tempo.

## Projetos apresentados

- Sistema de Gestão de Biblioteca — projeto acadêmico de análise de requisitos, prototipação e UML.
- [ChatBot FURIA](https://github.com/Geovanarlx/ChatBot-Furia) — chat web com respostas pré-programadas e demonstração publicada no Netlify.
- [XDEVS](https://github.com/Geovanarlx/projeto-xdevs) — vitrine interativa de personagens, feita com HTML, CSS e JavaScript.
- [Learning Page](https://github.com/Geovanarlx/Projeto-Learning-Page) — landing page com formulário e carrossel interativo; responsividade registrada como melhoria futura.

## Como visualizar

Abra `index.html` no navegador ou abra a pasta no Visual Studio Code e use a extensão Live Server.

## Antes de publicar

- Substitua `seu-email@exemplo.com` pelo endereço que deseja divulgar.
- Adicione o link correto do LinkedIn.
- Confira o texto, datas e níveis de idioma para garantir que continuam atuais.
- Confira se as demonstrações externas continuam disponíveis antes da entrega.

## Tecnologias demonstradas

- HTML5 semântico e navegação por âncoras.
- CSS responsivo com Flexbox, Grid, estados de foco e preferência por movimento reduzido.
- JavaScript para menu mobile, ano automático e animações discretas de entrada.

## Publicação

O site é estático e pode ser publicado pelo GitHub Pages. Depois de criar o repositório, envie os arquivos e ative Pages nas configurações do repositório.
