# Portfólio pessoal — Geovana Rogério Lima

Portfólio digital criado para apresentar a trajetória acadêmica e pessoal de Geovana Rogério Lima, suas habilidades e projetos. O site foi desenvolvido com HTML, CSS e JavaScript, com identidade visual própria, layout responsivo e navegação adaptada a dispositivos móveis.

- **Portfólio publicado:** [geovanarlx.github.io/Portifolio-Geovana-Lima](https://geovanarlx.github.io/Portifolio-Geovana-Lima/)
- **Repositório:** [Geovanarlx/Portifolio-Geovana-Lima](https://github.com/Geovanarlx/Portifolio-Geovana-Lima)

## Projetos apresentados

- **Sistema de Gestão de Biblioteca** — análise de requisitos, protótipos de interface, diagramas de sequência e modelagem.
- [**ChatBot FURIA**](https://github.com/Geovanarlx/ChatBot-Furia) — chat web com respostas pré-programadas.
- [**XDEVS**](https://github.com/Geovanarlx/projeto-xdevs) — vitrine interativa de personagens.
- [**Learning Page**](https://github.com/Geovanarlx/Projeto-Learning-Page) — landing page com formulário e carrossel.

- [**Relógio visual acessível**](https://github.com/Geovanarlx/PrototipoRelogio) — experimento full stack com sinais visuais para sons do ambiente.
- [**Coletor de anexos da ANS**](https://github.com/Geovanarlx/Quest-1---python) — automação em Python para baixar PDFs e reuni-los em ZIP.

## Criação do projeto

O portfólio organiza em uma única página a apresentação pessoal, competências e experiências acadêmicas e pessoais. A estrutura foi construída com HTML semântico, estilizada em CSS e complementada por interações em JavaScript. A identidade inclui monograma vetorial original e elementos animados sutis.

## Recursos

- Layout responsivo para celular e computador.
- Tema claro e escuro com transição e preferência salva localmente.
- Animações e revelação de conteúdo com suporte à preferência por movimento reduzido.
- Menu para dispositivos móveis, navegação por âncoras e foco visível.
- Monograma vetorial original em SVG.
